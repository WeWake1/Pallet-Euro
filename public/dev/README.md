# Development assets only

Wood textures (derived from CC0 ambientCG Wood096) and EPAL / IPPC stamp images for the local prototype.
The EPAL oval must not be published before the EPAL licence is granted. Delete this folder before launch.

`r4/`: the round-4 hero renders (Blender, `tools/render/hero/`). They show the EPAL oval and the `IN-XXX HT` placeholder, so they are dev-only like everything here.

`r5/` (round 5: the heroes "Two worlds", "In its place", "Look inside" and the scroll stories "The Mark" and "Your next container") is rendered by `tools/render/hero/` with the same dev marks (EPAL oval, `IN-XXX` placeholder). Dev only; re-render before launch. `*-sm` folders and files are the phone versions (every second frame, 800 px; stills 1200 px), made with `cwebp -resize`.
